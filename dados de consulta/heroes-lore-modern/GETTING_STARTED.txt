2. RODAR EM SEU DISPOSITIVO

  W/↑ = Cima          P = Pausar

  Y = Interagir

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"flutter pub get" falha:
  → flutter clean && flutter pub get

"build_runner build" lento:
  → flutter pub run build_runner build --delete-conflicting-outputs

App lento no Android:
  → flutter run --release

Web não funciona:
  → Atualizar Chrome/Firefox
  → flutter run -d chrome --web-renderer=skwasm

Não consigo rodar em iOS:
  → pod repo update (em ios/)
  → flutter clean && flutter pub get && flutter run -d ios
